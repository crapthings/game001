## 城市层级

世界区域 → 城市 → 功能分区 districts → 街区 blocks → 地块 parcels → buildingId。功能分区按用途归组，可包含不相邻街区。工业区由 seed 选择城市一侧，商业区主要沿中心道路，住宅填充外围；中大城保留公园街区。地块保存建筑 ID、入口和规划包围范围，不将其直接用作室内导航。

公共设施先分配，随后普通建筑按沿街候选点填充。普通建筑池中不含医院、学校、消防站、诊所或警务站；设施配额单独维护。

这些是适配 4.19 平方公里游戏区域的设计配额，不是现实城市人口服务标准。设施位置无法满足占地、道路或后续区域公路避让时允许少于配额；不为凑数强塞或复制。大型设施独占街区的建筑配额，诊所和警务站可共享。区域公路删去建筑后会同步清理 facilities、parcels、院落等引用。

住宅、商业、工业、公共区的占地覆盖上限分别为 34%、44%、30%、24%，包含建筑碰撞余量；上限不要求填满。大型设施优先占地，不受普通建筑填充率限制。其余空间留给前后院、通行与装卸。沿街候选间距根据功能区与 seed 变化，小地块尝试较小模型，无法放置则保留空隙。

普通城市建筑偏转约 ±2–3°，工业约 ±1°；公共设施保持临街朝向。商业退让变化最多 0.6m，住宅最多 1.6m。村庄住宅混合横向/纵深模型，偏转最多 ±2.5°，轻微调整位置。每次放置后检查旋转占地、道路、街区边界与建筑间距；后院组合跟随建筑朝向。所有随机流由 seed 和稳定街区/地块 ID 派生。

新城市记录 urbanPlanVersion=2，新村庄记录 parcelPlanVersion=2。已有世界不重建，需使用未保存过的 seed 查看新布局。遵守项目规则，不运行测试、build 或 lint，仅作语法及静态检查。
