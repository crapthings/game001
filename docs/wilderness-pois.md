# 野外 POI 首版

当前优先世界规划、地形和环境。此批接入静态场景，不包含搜刮、任务或室内玩法。

- 六种配方：废弃加油站、路边维修站、护林小屋、废弃营地、独立农舍、野外泵站。复用现有建筑与环境模块；护林小屋暂用灰墙平房，通信塔待专用资产。
- 每种最多两处，总目标 12 处；每个宏区最多三处，同类中心至少相距 600 米。目标不是保底，不合格候选会跳过。
- 依据主路生成有限候选，林地、农田、湿地配方检查主导生态；采样占地高差、坡度与湿度，避让开场、其他聚落和道路。支路检查自然地形坡度及已有地点范围，不代表完成驾驶工程校验。
- 使用 `kind: poi` 的小型聚落记录接入已有整平、散布排除、资产加载、碰撞与存档；入口短支路接到已有公路。沿用现有道路表面，土径材质后续优化。
- 地图全域显示菱形地标，放大后显示名字；迷雾沿用探索裁切。规划页显示实际生成数量与目标数量。
- 新种子生效，已有快照不补生成。`poiPlan` 保存配方版本、实际数量与未能放置的 ID。

未运行测试、build、lint 或游戏内验收。后续画面验收重点：各类地点出现率、支路接缝、建筑贴地、野外留白和素材重复感；尚无性能测量结论。
