# 开放世界末日生存：长期核心规划

日期：2026-09-07。状态：产品与架构规划，未实现部分不能视为现有能力。

## 1. 游戏定位

单人开放世界末日生存，以探索搜刮、资源采集、制作、据点建造为长期循环，战斗用于争夺资源、突破封锁和保护据点。密集尸群是部分区域和事件中的压力，不作为全地图永不停歇的唯一内容。

核心循环：发现目标 → 准备装备和背包 → 探索/采集/战斗 → 携物资撤离 → 储存/恢复/制作/建造 → 解锁更远、更危险的目标。

玩家每次出门应有明确需求，如找水、找药、找油、找工具或找建材；目标区域的资源类型能帮助玩家作决定。收获既包括物品，也包括安全路线、地图信息和新配方。

## 2. 当前基础与缺口

已有：种子世界、地形生态、聚落与 POI、分块加载、探索地图、昼夜、体力与饥渴、基础背包及消耗品、武器/手雷、丧尸追击与死亡记录。

尚缺：正式掉落与搜刮容器、资源节点采集、工具、制作配方与工作台、建造及建筑持久化、玩家生命/受伤/死亡循环、可搜索室内、装备获得与成长、车辆燃油循环。

目前四枪与手雷初始发放、无限资源开关、持续临时尸群属于战斗原型和开发便利，不能直接作为正式生存经济。旧存档保留，不自动扣除已有装备；正式开局使用独立的开局配方版本。

## 3. 资源来源原则

普通丧尸不掉枪、不掉弹药、不掉手雷、不掉通用武器零件。感染者仅携带符合其身份的少量随身物品，可以一无所获。原有衣着变种只改变外观，不意味着额外奖励。

| 来源 | 主要物资 | 限制与作用 |
| --- | --- | --- |
| 普通居民感染者 | 小额零钱、钥匙、打火机、少量布料或个人杂物 | 允许空掉落；不作为稳定食水来源；零钱的交易用途留到后期 |
| 工人/维修人员 | 金属废料、线材、紧固件，低概率小工具 | 根据职业掉落，不能拆出无限工业物资 |
| 医护感染者 | 未开封医用耗材，低概率药品 | 稀少；普通衣物不能直接变成无菌绷带 |
| 警务/安保人员 | 手电、电池、少量对应弹药，极低概率损坏枪械 | 必须来自明确装备型角色；限区域、限数量，不让换皮普通怪提供枪 |
| 防护服/危险作业人员 | 滤芯、防护材料、区域线索 | 与工业/污染区域绑定；污染机制后置 |
| 特殊变异感染者 | 特殊材料或研究样本 | 后期制作/研究用途，不必让所有变异体吐枪械 |
| 营地、民居、便利店 | 食水、生活工具、布料、背包 | 日常生存供给的主要来源 |
| 诊所、药房、医院 | 药品、消毒品、医疗包 | 医疗需求驱动风险更高的探索 |
| 警局、军用检查站、特定武器柜 | 武器、弹药、配件 | 枪械资源的主要来源，需要对应地点和风险 |
| 修车棚、加油站、车辆 | 燃料、车辆配件、工具、电池 | 车辆需区分油箱、后备箱和可拆部件 |
| 仓库、工地、回收场 | 大量建材、金属、工具 | 重量高，推动运输和据点选择 |
| 农场、温室、谷仓 | 食物、种子、农具、肥料 | 种植生产在基础生存之后引入 |

建议先做有限且有用途的物品目录。没有消费用途的资源不批量投放，避免背包被无意义杂物占满。

## 4. 搜刮与掉落

世界中的柜子、箱子、背包、尸体和车厢都使用统一容器接口，但各有容量、掉落表与交互条件。敌人碎裂后用一个可搜刮残留点承载物品，不让每块视觉碎片成为拾取对象。

第一版：E 交互打开容器，显示双方背包，支持单件转移/全部拿取；满包或超重时只拿得下的部分，其余留在来源。普通敌人空掉落不生成空包。手动丢弃的物品形成世界物品堆，支持重新拾取。

掉落结果由世界种子、实体 ID、掉落表版本确定，并在首次生成时保存；重新进游戏、反复开箱、区块卸载不能重抽。已搜刮或击杀状态与转移结果一起提交，失败可重试但不能重复领取。

永久地点的容器默认不因刷新或重载恢复。临时尸群首版不提供可长期囤积的掉落，防止无限刷怪破坏经济；若后续允许，必须用遭遇配额控制。大型活动的奖励按事件结算，而不是无限叠加每只怪的收益。

不在 UI 拖拽开始时写存档；拖放是物品转移/快捷绑定的操作入口，松手通过游戏规则验证后提交。快捷栏储存引用，不复制物品。武器也应逐步成为可追踪的装备实例。

## 5. 自然资源采集

自然环境分为视觉装饰和可采集节点。不会给每根草、每粒碎石或每棵远景树都创建交互对象。

| 节点 | 工具/动作 | 产出 | 状态变化 |
| --- | --- | --- | --- |
| 地面松枝、松散石块 | 徒手拾取 | 少量树枝、小石块 | 拾取后消失 |
| 可伐树木 | 斧头连续砍伐 | 木材、树枝 | 健康树 → 受损 → 倒伏表现 → 树桩 |
| 枯木、倒木 | 徒手少量或斧头高效 | 干木、树枝 | 分阶段耗尽 |
| 可开采岩石 | 镐 | 石料，矿区节点可含矿石 | 受损 → 缺损 → 耗尽 |
| 纤维植物 | 徒手/刀具 | 植物纤维 | 采完变稀或消失 |
| 废金属堆、废车 | 撬棍/扳手等 | 金属、线材、有限零件 | 按部位逐步拆解，独立记录 |
| 水源 | 容器取水 | 未处理水 | 自然水源持续供给；净水须加工 |

苔藓只是石头的表面外观，默认产石料，不因绿色装饰另造资源。资源节点只在附近启用交互与碰撞；掉落以小堆/容器合并，不生成数百件刚体。

采集消耗时间和体力；工具影响效率，后续增加耐久。工具缺失时仍应能从松散资源获取基础材料，避免配方要求工具、造工具又要求先有工具的死锁。

树木不依靠重新加载恢复，矿石不短时间刷新。后续如做再生，用游戏时间和节点阶段记录；离线推进是否允许另行设计。

## 6. 生存系统顺序

第一层：生命、食物、水、体力、基础医疗、安全休息。敌人接触攻击有前摇、范围和冷却，不能每帧扣血。死亡规则需与物品实例和尸体容器同步设计；首版建议身上物资落入死亡背包、据点库存保留，在出生点/床位复活。

第二层：食物加工、净水、伤口、工具与武器耐久。先让状态变化可理解，再引入感染或更复杂治疗。

第三层：温度、天气暴露、食物腐坏、污染、疾病。均需对应可获得的解决手段，不一次堆满负面数值。

第一轮不引入复杂营养、逐部位伤害或多种弹药制作链。必须保留短途搜刮与安全整理的节奏，不能让饥渴和尸群同时迫使玩家不停操作。

## 7. 制作与建造

制作依赖配方、工具和工作站，消耗与产出遵循同一个原子物品事务。首版少量配方即可覆盖木材/石料/纤维的基本用途。

建造第一组：营火、储物箱、简易床位、基础工作台、木围栏、木门。第二组：地基、墙、屋顶、集水器、种植箱、烹饪与净水设施。第三组：金属加固、发电机、供电照明、维修台、自动防御和车辆设施。

放置流程：选择配方 → 半透明预览 → 合法/非法反馈 → 旋转 → 确认消耗 → 写入建造实体。判定坡度、支撑、碰撞、世界边界、道路及开场/剧情保留范围；不能把门封进墙内或切断必经剧情路径。

建筑必须接入角色与丧尸寻路、弹道遮挡、损坏维修、拆除返还、分块加载和存档。门的开关立即让导航缓存失效。后期允许丧尸攻击挡路的玩家建筑，避免一面廉价墙永久阻挡整个尸群。

据点不是大范围永久无敌区。首版先提供安全整理和储物功能，再设计噪声吸引、设施维护与有预告的袭击；不默认每晚强制攻城。

## 8. 世界与 PCG 的职责

2×2 定义宏观气候、地势和资源倾向；4×4 分配聚落与野外比例；8×8 分配林地、石料、农田等资源群落；16×16 负责 POI、场景与建造保留约束；32×32 负责局部资源节点、容器候选、散布预算和净空。管理格边界不成为视觉硬边界。

初始种子快照负责世界底图，玩家变化另存：树被砍、石被挖、箱被拿空、门被打开、房被建造。重新生成区块必须应用这些变化，不能覆盖它们。

创建世界时校验初期可达的物资链：近处有松枝/小石、至少一处生活补给搜索点和潜在水源，较远有工具/医疗/燃料来源。不保证所有资源在开场旁边，也不承诺每个容器必有目标物品。地形、路网、尸群强度一起决定获取成本。

危险分层：安静采集地 → 普通道路/村庄 → 城市/工业点 → 高价值特殊点。密集尸群集中在城市、事件和高风险设施；野外有巡游小群，允许玩家规划安静路线。现有临时尸群导演保留为调试/战斗区域能力，未来由区域压力、玩家噪声和事件统一调度。

## 9. 核心数据与性能约束

- 物品定义：类别、重量、堆叠、用途、标签；装备实例：耐久、配件、弹匣等状态，与定义分离。
- 容器：稳定 ID、内容、容量、归属、版本。玩家背包与世界容器共用转移规则。
- 资源节点：稳定 ID、类型、阶段、剩余量、版本。渲染碎块不参与权威状态。
- 建造实体：实例 ID、配方、位置/朝向、生命、支撑或连接关系、内部容器 ID。
- 世界变化按区块保存，修改才写；场景组件读取权威状态，Zustand 承担界面同步，避免每帧保存大数组。
- 拾取、采集、制作、建造必须防止重入与双重提交；多标签页保留已有版本冲突检测。
- 自然资源碰撞、玩家建筑碰撞、丧尸导航必须共享最新障碍信息；使用空间索引和有界对象池，不扫描全世界。
- 地面掉落有明确上限、合并和清理策略。重要装备与死亡背包不因离屏自动删除；仅卸载视觉，内容仍持久化。普通临时掉落如需过期，要有可见规则。
- GPU 后续承担视觉密度、粒子等工作，权威物品归属与资源扣除不依赖 GPU。

## 10. 分阶段实施及验收

| 阶段 | 交付 | 通过标准 |
| --- | --- | --- |
| P0 统一物品与容器 | 物品目录、世界容器、转移、地面物品、存档 | 满包不丢物、刷新不重抽、转移失败不复制 |
| P1 搜刮最小闭环 | 一个生活 POI、柜子/箱子、身份掉落表 | 出门取食水/材料、带回保存，普通怪不产武器 |
| P2 采集最小闭环 | 松枝/石块、斧镐、树/岩石节点 | 采集消耗体力、有产出，卸载与重进保持耗尽状态 |
| P3 制作与据点 | 基础配方、箱子、营火、工作台、床位、围栏门 | 能收集材料建成据点并重进恢复，通行与弹道正确 |
| P4 生存与风险闭环 | 丧尸攻击、生命医疗、死亡背包、区域尸群规则 | 能撤退恢复，死亡损失明确，采集/搜刮不被全图无限尸群打断 |
| P5 成长与生产 | 装备耐久、维修、种植、净水、供电、车辆燃油 | 出现新的物资需求与远途目标，资源有持续消耗出口 |

P0–P1 优先，避免先加几十种掉落但没有可靠的物品流转。P2–P3 连续交付，让野外材料尽快有实际用途。P4 的生命/攻击原型可在 P1 后穿插，但完整死亡循环必须依赖可靠容器。各阶段不以新增素材数量作为完成标准。

下一次具体实施：整理物品定义与统一容器接口，选一个已生成的农舍/营地放入可搜索容器，先打通 E 搜刮与存档；暂不把 dnd-kit 拖拽或大量随机武器掉落当作前置条件。

## 11. 初期经济检查

以一次往返探索作为单位记录：耗时、消耗食水/弹药、拾取重量、有效材料、被迫丢弃物品及用途。关注缺什么、为什么出门、回家能做什么，而非只看掉落数量。

暂不锁定稀有掉率、采集次数或制作成本。第一版小规模物品集运行后再调参，避免没有消费链就承诺固定概率。所有物资都要能追溯来源，也要有明确使用或加工出口。

本轮仅规划与代码现状核对，未运行测试、build 或 lint。
