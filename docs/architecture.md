# 世界架构

## 约定

这是人工规划区域、seed 驱动内部布置的连续 3D 世界，不是体素或挖方块系统。
当前为固定 45° 俯视探索原型：连续地面按隐藏网格分块，角色附近加载、远处卸载。区域边界只用于语义和内容覆盖，不绘制圆形底座。

世界一致性 = seed + generatorVersion + 区域定义版本。创建时保存完整规划快照，之后直接读取快照。
同种子的新世界在同版定义下结果一致；已有存档不随代码更新自动重新生成。
玩家进度与基础规划分开，探索和标注不改变程序生成结果。


生成器不依赖 React、Babylon 或浏览器，输出可序列化数据，未来可直接搬入 Worker。
Babylon 对象仅存放于运行时，不进入 Zustand 或存档。Zustand 不保存逐帧坐标。
世界规划变化才重建运行时；探索、位置检查点等低频事件只更新进度。
区块为 32×32 单位，加载玩家周围 5×5 个区块，超出 7×7 保留范围卸载。初始生成 25 块，后续每帧至多生成 2 块；中心改变时重新排队，取消未生成的旧需求。
相同素材共享模板与材质并使用实例；卸载区域不销毁共享模板，世界释放时统一销毁。
已有跨区块移动与按区块数量限制的生成队列；仍为主线程同步生成，没有 Worker、时间预算调度或 LOD。已加载区块最多 49 个，未实现超远距离浮点原点迁移；“无限”指按坐标按需生成的体验，不保证无限坐标精度。

## Seed 与稳定 ID

- Seed 为去除首尾空格、Unicode NFC 规范化的 1–80 字符串，大小写敏感。
- 随机流由 seed、生成器版本、区域 ID/修订号、散布层 ID、对象序号组合确定。
- ID 如 `whisper-woods/trees/5` 是进度和交互引用键，不能用数组位置或模型文件名代替。
- 新区域不会消耗其他区域的随机数；对象之间仍有避让规则，因此修改既有散布层需要视为区域修订。
- 人工区域中心、半径、地标和连接保持固定；seed 改变区域内部的装饰位置、方向和大小。
- 创建时快照持久化；版本不兼容或损坏时拒绝加载并保留原始数据，不能偷偷重置世界。

## 添加区域

在 `regions/definitions.js` 添加一项：

```js
{
  id: 'eastern-coast', revision: 1,
  name: '东海岸', biome: 'coast',
  center: [105, 0], radius: 18, color: '#77aabb',
  description: '海岸探索区', tags: ['海岸'],
  connections: ['sunstone-ridge'],
  landmarks: [
    { id: 'harbor', label: '港口预留点', offset: [0, 0], assetId: 'landmark.harbor' },
  ],
  scatter: [{ id: 'rocks', assetId: 'nature.rock', count: 8 }],
}
```

`center` 与 `offset` 均为 [x, z]，当前区域边界采用圆形。地标周围保留空间，中心带预留通道。
校验包含重复 ID、范围、重叠、连接目标与地标越界。connections 当前为规划元数据，尚不生成道路。
新世界自动包含新定义；旧世界由开发工具调用 `useWorldStore.getState().addNewRegions()`，只追加新 ID，已有区域、对象、探索、备注保持原样。玩家界面不提供规划编辑工具。
修改旧区域不会通过同步覆盖旧快照。正式修改旧区域需要显式迁移，不能靠提高版本号强制重算。
如新区域与旧存档快照重叠，扩展被拒绝，原存档不改动。

## 替换素材

规划只记录 `assetId`、位置、旋转、缩放和稳定对象 ID。
修改 `createAssetRegistry.js` 对应工厂即可替换树、石头和地标，规划与进度无需变化。
模型约定：Y 向上，底部枢轴位于地面，保持代理外观的合理占地范围。
未来异步 glTF 加载需加入缓存、任务取消和加载完成后的会话检查；碰撞体应独立定义，不能依赖外观网格。
未知素材显示占位物，避免新增逻辑资产导致整个世界无法打开。

## 进度与存储

存档：`schemaVersion`、写入 `revision`、`world` 规划快照、`progress`。
当前进度：已探索区域 ID、区域备注、角色位置；旧版 lastRegionId 保留但不再用于角色出生。flags 为未来扩展预留，暂无任务系统。旧档没有角色坐标时从 [0, 0] 出生。
探索操作幂等，角色进入区域自动发现。旧备注数据与底层编辑 API 保留，游戏内编辑面板已删除。位置每 2 秒保存一次，并在暂停、离开页面时补存；存储失败保留错误提示。点击前往使用直线导航与简单滑动碰撞，暂未实现全局寻路。
每个 seed 独立存档；成功写入后才确认进度。旧页面的 revision 不匹配时拒绝覆盖并提示重新进入。
当前使用可注入的 localStorage repository，适合少量区域原型；受浏览器容量、清理和设备隔离影响，不提供跨设备同步。
revision 检测可拦截顺序发生的过期写入，但 localStorage 不支持原子跨标签事务，暂不支持多个页面同时编辑。
扩大世界前改为 IndexedDB 事务：规划按区域存，进度按对象/区域存，保留 repository 边界。
当前没有删除或重置存档按钮，也不会自动迁移未知版本。

## 俯视镜头与连续世界

镜头采用正交投影，水平斜向 45°、俯角 45°，固定方向跟随角色，不开放拖拽旋转。视野宽度封顶，避免超宽屏看到未加载区块。鼠标点击地面、WASD 或方向键移动，暂停与失焦清空输入。

网格是不可见的管理单位，不是方块玩法。地面网格在全局坐标采样高度和颜色，共边顶点与法线一致；角色按实际三角面插值落地。散布使用 seed + 地形版本 + 区块坐标 + 对象序号，卸载再加载结果一致。

地形生成器版本当前固定为 TERRAIN_VERSION=1，现有世界也按此版本解释。以后修改地形算法必须保留旧版实现和明确迁移入口，不得直接修改 v1 行为。区域快照继续用于覆盖默认散布；地标代理暂不渲染，真实交互素材后续接入。
