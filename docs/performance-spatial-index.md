# 空间查询优化

本轮只修改候选检索方式，保留原精确碰撞、生成距离、追击速度和数量上限。

- 静态碰撞采用 8 米空间格。旋转矩形按世界坐标外接范围登记，跨格障碍登记到全部相交格；查询结果去重。查询范围覆盖原矩形局部轴半径膨胀，随后沿用原圆形/旋转矩形精确判定。动态车辆与路障仍实时采样。
- 区块安装完成时登记碰撞，卸载时移除，世界销毁时清空。索引不会保留已卸载物体。
- 丧尸分离采用 2 米空间格，每次 AI 更新重建，只查询 1.2 米附近个体；个体移动后更新位置，释放时删除引用。
- 静态出生点采用 32 米空间格，初始化一次。每帧仅查询准备范围覆盖的网格，再沿用距离过滤与稳定排序。

仍有待优化的开销：可见性建筑遍历、死亡记录集合重建、模型创建与材质、弹道线分配。索引增加少量内存来减少全量扫描；未进行性能采样，不提供帧率增益结论。

按项目要求未运行测试、build 或 lint。本轮静态检查了负坐标网格、旋转包围范围、跨格去重和索引释放路径，尚未游戏内验收。

## 渲染资源与短期复用

- 丧尸材质按场景与颜色共享，通过引用计数释放；单个模型死亡不会销毁其他模型仍在使用的材质，最后一个使用者释放时才销毁。
- 弹道使用 24 条可更新线网格，复用端点与颜色；普通射击、霰弹多弹丸和爆头均复用，超出容量覆盖最旧效果，不影响命中计算。
- 仅刚击杀模型进入短期池，最多 8 个，3 秒游戏时间内未复用即销毁。同类补怪复用时重置动画相位、旋转和可见度；位置、生命值、追击状态仍重新初始化。远距离卸载不入池。退出世界清空模型池和弹道池。
- 本轮未调整动画更新频率，避免影响已完成的步态与位移同步。尚未实测性能；未运行测试、build 或 lint。
