# 背包 v1

B 打开或关闭背包，Esc 关闭；左下区域提供按钮入口。背包使用独立 inventory 阶段，与地图互斥，打开时清空移动输入、保存位置并暂停人物、体力和昼夜时间。关闭后继续游戏。

容量 24 格、20 kg。同类物品可堆叠，各物品有独立堆叠上限和单件重量。点击选择物品；移动模式再点目标格，可移动、交换或合并同类堆叠；拆分把一半数量放到第一个空格；整理合并同类物品并按稳定 ID 排列。背包无法容纳的添加请求整体失败，不做部分写入。

`game/inventory/items.js` 定义可携带物品，与场景模型 ID 分离。玩家初始不携带任何道具，24 格背包与 10 格快捷栏均为空，负重为 0 kg。饮水、罐头、绷带和零件保留物品定义，供后续搜刮添加。饮水和罐头可补充水分与饱食度；治疗、装备和世界掉落尚未开放。

`game/inventory/inventory.js` 管理默认内容、重量、校验和纯数据变更。未来搜刮通过进度事件 `{ type: 'inventory', action: 'add', itemId, count }` 接入。背包记录位于 `progress.inventory`，包含 version 和固定长度 slots；空格为 null，非空为 itemId/count。

所有操作走现有世界 Store 串行存档队列，使用最新进度执行并在 IndexedDB 写入成功后发布，位置检查点保留背包字段。旧档缺少该字段时显示空背包，第一次背包操作写入；已有背包物品保持原样，数据损坏时读取报错，不默默重置。不同 seed 的背包独立。

界面采用 Tailwind，包含对话框语义、键盘焦点限制、操作状态反馈和窄屏滚动。遵循项目规则，未运行测试、build 或 lint。
