# 2048 世界规划 v2

## 空间约定

1 单位 = 1 米。X/Z 范围为 [-1024, 1024)，共 2048×2048 米，Y 为高度。区域边界、建筑落点和生态散布位置使用整数米；模型部件和角色运动保留小数精度。1×1 是空间尺度，不是方块建造玩法。

世界划分为 4×4 个相邻区域。内部三条横纵分界线由 seed 扰动，所有区域共享边界，因此完整覆盖且无重叠。边缘限制移动并停止加载外部区块。

## 规划流程

1. 使用独立布局随机流确定分界线和区域类型；稳定 ID 为 `district-行-列`。
2. 分配 3 个城市区、4 个村庄区、9 个自然区；包含原点的区域固定为村庄类型。
3. 每区设置一个基础生态与 3 个子生态斑块，全世界共 48 个斑块。
4. 为城市、村庄生成聚落，按道路两侧排列建筑及独立院落模块。
5. 用最小生成树和整数米折线连接 7 个聚落；城市使用圆角环路与纵横街道构成街区路网。
6. 建筑及装饰避让跨区道路，保存规划快照。角色出生在起始村庄主街上。
7. 运行时仅生成附近地面和生态散布，地图直接读取快照。

## 区域与生态分离

`kind` 表示城市、村庄、野外；`biome` 表示基础地表生态。城市区内也可以有林地和草甸，村庄区内可以有湿地。

| 基础生态 | 地表与资产倾向 |
| --- | --- |
| urban | 灰褐地面、城市设施、工业残骸 |
| farmland | 平缓农地、草捆、田垄、灌木 |
| woodland | 起伏林地、树木、倒木 |
| meadow | 草甸、花丛、灌木 |
| wetland | 低洼湿地、芦苇、枯树；当前无水体模拟 |
| scrubland | 荒地、枯树、岩石和废料 |
| quarry | 石质坡地、岩石和工业遗留物 |

生态参数包括颜色、海拔、起伏、散布密度、资产权重。区域边缘约 32 米混合，子生态边缘约 24 米渐变。聚落地基与道路覆盖生态高度，避免地面穿过建筑。

## 城市与村庄

城市采用圆角外围环路与横纵各三条道路，形成 16 个功能街区，详见 [城市路网](roads.md)。街区区分住宅、商业、公共设施、工业和公园，建筑面向附近道路。村庄保留 7 米宽主街和最多十个建筑地块，使用 [专用乡村建筑](village-buildings.md)。路网避让后实际建筑数可能减少。

跨区公路宽 6 米，拐角使用曲线过渡。街区道路、出城支路和跨区公路共用破损路面显示，未连接末端渐隐到地面。当前路网尚无交通、桥梁或全局寻路。

## 独立资产与组合

保留 10 类建筑，新增 19 类环境模块：

- 自然：阔叶树、枯树、灌木、芦苇、花丛、原木堆。
- 农村：围栏、草捆、田垄。
- 城市：路灯、长椅、垃圾箱、混凝土路障。
- 工业：木箱、油桶、集装箱、发电机、水罐、废铁。

模块在 `assets/environment/catalog.js` 定义，部件支持 box、cylinder、sphere；几何构建统一放在 `createEnvironmentModel.js`。材质合并后创建共享模板，场景中复用实例。

三个组合 `yard.worksite`、`yard.farm`、`yard.rest-stop` 只引用模块与局部偏移。`expandAssembly` 将组合展开为独立对象，组合旋转会同步变换偏移。碰撞和未来交互仍以子对象为单位。围栏预留端点 sockets，尚未实现自动吸附编辑器。

## 后续扩展入口

- 新模型：新增 catalog 项及占地/半径，再加入生态权重或组合。替换几何保持 assetId 不变。
- 新组合：在 environmentAssemblies 中引用已有模块，无需创建专用大模型。
- 新生态：增加 biomeCatalog 配方，再加入生成器区域或子生态候选池。
- 区域备注：沿用 progress.annotations 的 regionId 索引，不改变世界布局。
- 新街区：扩展 createRegionalSettlement 的地块规则，保持对象 ID 稳定；新世界采用新配方版本。
- 改变区域布局：调整 generateWorld 的规划配方并增加版本，或编写显式迁移。当前世界已全覆盖，不支持向既有快照直接追加重叠区域，旧 addNewRegions 调用会报出原因。

布局快照不会随刷新重新生成；程序化地形与模型仍依赖代码配方，后续改变外观或地形算法必须维护版本约定。
