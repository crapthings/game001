# 开发者资产目录

独立路由 `#/assets` 展示当前程序化资产的名称、assetId、分类和近似尺寸。开始菜单底部提供开发者入口，页面可独立刷新，不读取世界存档或启动区块 Worker。

目录按资产形态分为道路、角色、建筑、自然生态和场景道具五个 Tab。道路提供十种路段及连接样例，复用实际游戏路面渲染，详见 [道路规划](world-road-plan.md)。城市、村庄作为区域标签，与工业区、农田、森林、湿地、公路、荒野、通用并列。同一资产可以属于多个区域，例如路灯可用于城市、村庄和公路。

清单与区域归属由 `game/assets/assetManifest.js` 从正式 catalog 派生，避免维护第二份建筑 ID。每项资产包含 `type`、`category`、`zones`、`tags` 和米制 `size`：type 对应 Tab，category 描述模型功能，zones 表达区域归属，tags 保留更细的楼层、玩法与制作标签。`selectAssets` 可组合区域、形态和标签得到稳定顺序的候选池，再由 seed 系统选择；通用资产会自动进入任意区域池。页面第二行区域筛选只过滤当前 Tab，不会加载其他模型。

`AssetGalleryPage`、`AssetPreview` 和 Babylon 预览代码通过 React.lazy 位于独立路由包中，普通菜单刷新不会加载。目录不会一次生成整个 Tab：单个 Canvas 和 Babylon Engine 只显示当前选中资产，切换时销毁旧实例、模板与材质，再构建新资产。切换 Tab 会记住各 Tab 上次选择。

页面使用占满视口的紧凑工作台布局：56px 顶栏、44px 分类栏、窄资产列表和自适应全宽预览。资产信息以浮层贴在预览左下角，小屏时列表切为两列横向区域。全部界面样式直接使用 Tailwind utility class。

预览支持鼠标拖动旋转与滚轮缩放，相机按照资产与参照人的组合尺寸自动取景。地面网格每格 1 米，每个资产旁固定显示 1.80 米真实玩家模型，便于检查人物、门、建筑和环境组件的真实比例。当前尚未展示碰撞盒、入口、sockets、LOD 或材质通道调试。

遵守 AGENTS.md，未运行测试、build 或 lint。

角色目录位于 `assets/characters/catalog.js`，模型工厂位于 `assets/characters/createCharacterModel.js`。游戏、角色预览和尺寸对比共用真实玩家工厂及待机动画；预览玩家自身时不重复创建参照角色。未来 NPC 在目录及工厂中登记，角色实例保留独立动画和释放接口。切换资产时销毁旧角色及其材质，只创建当前资产和必要的玩家参照。
