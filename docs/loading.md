# 游戏按需加载

应用使用 React Router 的 HashRouter 分成菜单 `/` 与游戏 `/game`。`GamePage` 通过 `React.lazy` 动态导入，因此首次刷新只加载菜单、路由、基础状态和少量世界存档代码，不加载 Babylon 引擎、场景、程序化模型工厂或地图界面。

点击“进入世界”后才授权当前内存会话并进入游戏路由。刷新会清空这份内存授权，即使地址仍是游戏路由也会返回菜单，避免刷新时自动恢复重型素材加载。返回主菜单会释放 Babylon Engine、场景、区块实例、纹理和共享模型模板。

加载进度分为动态模块、世界规划、图形引擎、素材预热以及附近区块。初始 5×5 区块由 Worker 计算地形、法线、散布与道路像素；主线程按约 3ms 软预算安装地面、道路和单个资产实例。素材模板逐帧预热，进度显示已完成区块与模板数量。两者完成后才切换为 playing，期间移动和世界时间均不推进。

移动时提前准备前方 24 米的区块窗口，近邻优先；最多一个 Worker 计算任务和一个待安装结果。过期结果丢弃，未完成的安装可取消；区块装配完成才启用显示和碰撞。卸载逐帧进行，退出世界终止 Worker 并释放未完成资源。

单次模板构建、GPU 上传和资源释放不可中断，因此 3ms 是软预算，不代表每帧耗时保证。路面裂缝的少量 Canvas 绘制仍在主线程；逐像素道路采样已在 Worker。尚未做运行时性能测量。

世界规划在点击开始后读取或创建。菜单初始化只读取最近一次 seed 字符串，不解析完整世界快照。进度条代表应用自身阶段和区块数量；浏览器下载动态 JavaScript 时无法获得可靠字节进度，因此该阶段显示固定起始比例。

遵守 AGENTS.md，未运行测试、build 或 lint。
