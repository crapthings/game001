# 体力与奔跑

按住左右 Shift 均可奔跑，支持键盘移动和点击地面前往；按 Shift 不取消点击目标。行走保持 2.2 米/秒，奔跑 5.5 米/秒，与 [世界尺度规范](world-scale.md) 共用米制参数。

体力上限 100，奔跑每秒消耗 8，满体力可持续奔跑 12.5 秒，平地约 69 米。停止奔跑 1.2 秒后，每秒恢复 20，行走也可恢复；从空体力到回满共约 6.2 秒。耗尽后进入力竭，恢复至 25 才允许再次奔跑；持续按住 Shift 时达到阈值后自动恢复奔跑。原地与完全被障碍阻挡时不消耗体力。

左下角 HUD 显示体力数值、进度条与行走/奔跑/恢复/力竭状态，低体力用琥珀色提示。奔跑时提高角色步频、摆臂幅度及身体前倾。

`game/entities/createStamina.js` 集中定义参数并管理运行时状态；场景使用实际位移判断消耗，`usePlayerStatusStore` 约 10Hz 发布 HUD 数据。暂停、地图与菜单冻结体力，切换阶段清空 Shift 和移动输入。

检查点保存 `progress.stamina` 的 current、exhausted、delay；体力单独变化也会触发保存。旧存档缺失此字段时默认满体力，已有记录恢复原状态，离线不计恢复时间。保存周期沿用位置检查点的 2 秒及离开游戏阶段、pagehide 补存。
