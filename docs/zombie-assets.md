# 丧尸资产

资产预览的「角色」分类提供十种程序化 low-poly 丧尸：灰衣游荡者、瘦骨疾跑者、锈盔工人、失落医护、余烬消防员、残甲防暴警员、泄漏防化员、浮肿重躯者、匍匐潜伏者、空喉嘶吼者。

`src/game/assets/zombies/definitions/` 每个变种独立文件，包含体型、姿态、颜色、职业装备零件、区域标签及说明。共用 `createZombieModel` 的关节与动作接口；`character.zombie.*` 是稳定资产 ID。后续可按同一 ID 替换模型工厂，不依赖建筑模板系统。

模型朝 +Z，根节点位于地面，初始化时按模型包围高度归一到定义米制高度。宽深为预览占位估计，尚不是战斗碰撞体；动作是程序化待机与原地步态，不是完整战斗动画。

预览仅创建当前角色，提供待机、行走、奔跑切换，并放置 1.8 m 玩家作参照。此阶段没有世界刷怪、AI、攻击、伤害或掉落。职业、敏捷、重型等标签为后续生成与行为配置预留，不代表已经实现对应能力。

## 同类外观变种

每类模型新增六组有限的衣服色调、肤色明暗和身体前倾组合；基础职业/变种轮廓保持不变。世界种子与敌人 ID 决定外观组合和体型，身高 90%–110%、宽度 85%–115%、厚度 90%–110%，不写额外存档字段。

模型池按资产与外观组合复用，根节点体型缩放在每次使用时重设。有限色板继续使用共享材质；不为每只敌人随机创建独有材质。步态周期距离与厚度缩放同步，命中半径、个体分离和移动碰撞按体宽调整，爆头反馈高度按实际身高调整。命中仍为简化平面半径，非模型精确碰撞；共享寻路网格仍是统一精度。
