# 游戏开发菜单

游戏内按 F2 或点击左上方「开发」，暂停菜单也提供入口。打开后世界暂停，F2 / Esc / 关闭按钮返回之前的游玩或暂停状态。

- 地图全显：M 地图和雷达跳过探索裁切与远处压暗，不修改 fog 或已发现区域；关闭后恢复真实迷雾。
- 无限奔跑：冻结当前体力与恢复冷却，忽略力竭及饥渴限跑。关闭后继续使用原体力状态；饥渴本身仍正常消耗。
- 奔跑倍率：1–4 倍，仅 Shift 成功奔跑时生效。移动以最多 0.2 m 小步检查碰撞，不跳过未加载区块限制。

设置在独立 Zustand store 中，只保留当前页面会话，不写入存档。调试期间的实际移动、探索、时间及生存进度仍按原流程保存。「恢复默认」关闭全部调试设置。入口变黄提示有调试设置启用。
