# 末日道路表面

道路包含柏油颗粒、裂缝与分叉、坑洞边缘、修补痕迹、油污、褪色破损标线，以及人行道接缝、积土和苔藓。路缘用少量几何体补充碎石和杂草。

`world/settlements/createRoadSurfaceCache.js` 使用 Canvas 生成 512×256 纹理，每段覆盖 32 米道路及两侧人行道。贴图通过 mipmap 和各向异性过滤减少远景闪烁，不依赖外部图片。
纹理由世界 seed、城镇 ID、道路 ID、路段坐标和表面版本共同确定；标线缺口额外使用全局标线编号，跨段保持一致。

`createStreetSection.js` 根据全局坐标映射 UV，再按世界区块裁切。南北相邻区块引用同一段纹理，不会各自生成不同裂缝。引用计数为零时释放贴图与材质；世界销毁时清理剩余缓存。
每个区块的碎石与杂草分别合并，最多增加两个装饰网格。装饰不参与碰撞，不妨碍角色移动。

坑洞目前为视觉纹理，不改变地面高度和角色碰撞。整体街道布局、道路宽度及存档中的地块位置保持不变。
后续可在相同路段 ID 下增加真正的塌陷、积水和路障；需要分别定义几何、碰撞及导航规则。
