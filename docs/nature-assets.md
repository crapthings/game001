# 自然生态资产

新增 12 件：白桦树、幼松、烧焦树干、腐朽树桩、倒伏树干、蕨类丛、枯草丛、香蒲丛、荆棘灌丛、覆苔巨石、碎石散落、蘑菇簇。

每件独立放在 `assets/nature/definitions/`，维护米制模型、区域与功能标签、碰撞范围和 variants。由 `nature/catalog.js` 自动登记默认及附加变体，再接入环境模型工厂；资产目录「自然生态」按需预览，沿用真实玩家参照。

白桦树约 6.5 米、幼松约 2.9 米；蕨类、草丛、香蒲、碎石和蘑菇 radius 为 0，可穿行。倒伏树干使用独立矩形占地，树木与巨石采用简化半径。变体函数必须确定性生成，不使用 Math.random；新增变体使用稳定后缀 ID。

本批为资产库扩充，尚未调整生态散布权重，已有世界生成结果保持原状。后续按生态选池时，可使用 tree、shrub、groundcover、rock 等功能标签区分大体量障碍与地表点缀。
